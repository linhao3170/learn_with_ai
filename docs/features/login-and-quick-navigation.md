# 登录入口与统一搜索

> 更新触发：登录入口、搜索结果或模块快捷跳转的行为变动时 | 上次更新：入口完善一轮（2026-09-26）
> 来源：`frontend/src/components/LoginDialog.vue`、`frontend/src/components/QuickSearch.vue`、`frontend/src/views/HomeView.vue`

## 目标

让用户从系统首页快速进入已经实现的页面和业务模块，同时提供一个不依赖后端账号服务的演示登录入口。分析引擎、图谱生成、判题和教学口径不在本功能范围内。

## 行为与边界

- 首页顶部的「登录」打开本地演示登录窗口；用户名与登录状态写入 `localStorage['lwai.demo.user']`，密码只用于当前提交校验，不发送到后端。
- 用户可以直接以游客身份继续；没有远程鉴权时，页面明确显示当前版本没有接入远程账号服务。
- 首页搜索框支持 `/` 快捷键，结果来自现有契约与固定页面入口：培训阶段、业务逻辑分析平台、旧版函数级分析、业务图谱和契约中的模块。
- 选择业务模块会进入业务图谱，并把目标模块传给 `BusinessGraphView`，自动打开对应卡片（如果快照没有该卡片，仍由原有后端兜底请求处理）。
- 搜索和登录只改变前端入口状态，不计算新的业务结论，也不复制一份引擎规则。

## 验收

- `node node_modules/vite/bin/vite.js build` 编译通过。
- 现有业务图谱、训练和逻辑平台入口继续由原组件承载；入口功能失败时不影响离线快照展示。

## 诚实边界

当前登录是本地演示身份，不提供账号注册、密码安全存储、权限控制或跨设备会话。真正的多用户鉴权仍属于后端 `/api/sessions` 与账号存储的后续工作。
