# 实验室设备借还与安全检查管理系统

## 业务问题

这个小型命令行系统用于管理实验室设备的借出、归还和安全检查。它把用户身份、设备台账、安全检查记录和借用记录串在同一条业务链上，避免设备被重复借出，也能在设备检查不合格时及时阻断借用。

## 模块职责

- `user_manager.py`：维护用户资料、角色、有效状态和登录会话，保证每条借用记录都能关联到有效借用人。
- `equipment_manager.py`：维护设备台账、存放位置和设备状态，负责可用、借出、维修、报废之间的状态更新。
- `safety_checker.py`：登记设备安全检查，按照检查结果和 30 天有效期判断设备是否满足借用准入条件。
- `loan_manager.py`：创建借用记录，执行借出、归还、撤销、审批、拒绝和逾期统计，并协调用户、设备与安全检查状态。
- `app.py`：提供命令行入口，准备示例数据并串起正常借还流程与安全检查不合格的拒绝流程。

## 三条核心业务规则

1. 同一设备存在状态为 `borrowed` 的活动借用记录时，不能再次借出。
2. 借用记录必须包含 `equipment_id`、`user_id`、`borrow_time`、`due_time` 和 `status`，借用人必须是有效用户。
3. 设备没有通过最近一次安全检查、检查结果为 `fail` 或检查超过 30 天时，不允许借用；检查不合格的设备会进入 `repairing` 状态。

## 运行方式

需要 Python 3.10 或更高版本，项目只使用标准库。进入项目目录后运行：

```bash
cd D:\learn_with_ai\lab_equipment_system
python app.py
```

程序启动时会建立示例数据：`E001` 通过安全检查，可以正常借用和归还；`E002` 检查不合格，借用会被拒绝。命令行菜单支持借用、归还、查看汇总报表和退出。

也可以在 Python 代码中按顺序调用各管理器的 `setup_config`，再调用 `borrow_equipment`、`return_equipment`、`cancel_loan` 或 `check_equipment_safety` 完成单步业务操作。
