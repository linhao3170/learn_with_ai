# 实验室安全助手系统（演示项目）

本项目是 LearnWithAI 平台的**项目级业务逻辑拆解训练**演示样本。

## 项目描述

一个高校实验室安全管理系统，用于实验室预约、设备管理、安全检查和用户权限管理。

## 模块结构

```
lab_safety_assistant/
├── __init__.py           # 包初始化
├── app.py                # 主入口，整合所有模块
├── user_manager.py       # 用户管理模块
├── reservation_manager.py # 预约管理模块（核心业务）
├── equipment_manager.py   # 设备管理模块
└── safety_checker.py     # 安全检查模块
```

## 四大核心模块

### 1. 用户管理模块 (`user_manager.py`)
- 用户注册、登录认证
- 角色权限（学生/教师/实验员/管理员）
- 用户信息管理、账户停用

### 2. 预约管理模块 (`reservation_manager.py`)
- 实验室信息管理
- 预约申请、审批、拒绝、取消
- 时间段冲突检测（核心算法）
- 预约状态流转（待审批→已批准→已完成/已取消/已拒绝）

### 3. 设备管理模块 (`equipment_manager.py`)
- 设备台账管理
- 设备借用与归还
- 维护记录
- 设备状态管理（可用/借出/维护中/报废）

### 4. 安全检查模块 (`safety_checker.py`)
- 检查项配置
- 安全检查执行与打分
- 隐患台账管理
- 整改跟踪（待整改→整改中→已完成）

## 模块间关系

```
用户管理 ──(创建人/审批人)── 预约管理
                              │
                              ├──(所属实验室)── 设备管理
                              │
                              └──(被检查对象)── 安全检查
```

## 核心业务流程

### 预约流程
1. 用户登录
2. 查看可用实验室
3. 提交预约申请（系统自动检测冲突）
4. 管理员/教师审批
5. 预约生效 / 被拒绝
6. 用户可取消预约

### 安全检查流程
1. 配置检查项
2. 执行安全检查（逐项打分）
3. 不合格项自动生成隐患
4. 指派整改责任人
5. 整改完成后关闭
